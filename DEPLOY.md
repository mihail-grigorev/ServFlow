# Руководство по бесплатному хостингу ServFlow

Проект **ServFlow** полностью готов к бесплатному облачному хостингу с поддержкой **автодеплоя** при каждом `git push`. Поскольку бэкенд FastAPI автоматически раздаёт собранный React 19 фронтенд (`frontend/dist`), всё приложение работает как **один веб-сервис** без проблем с CORS и без необходимости оплачивать несколько инстансов.

---

## Вариант 1: Render.com (Рекомендуемый, 3 минуты)

**Render** предоставляет бесплатный тариф (Free Web Service) с автоматической пересборкой при каждом `git push` в ваш GitHub-репозиторий.

### Шаг 1. Регистрация
1. Перейдите на [render.com](https://render.com) и войдите через свой GitHub-аккаунт.

### Шаг 2. Создание веб-сервиса
1. В панели управления нажмите **New +** → **Web Service**.
2. В списке репозиториев выберите `mihail-grigorev/ServFlow` (или вставьте ссылку `https://github.com/mihail-grigorev/ServFlow.git`).
3. Заполните настройки:
   - **Name**: `servflow` (или любое желаемое имя).
   - **Region**: `Frankfurt (EU)` (минимальный пинг).
   - **Runtime**: `Docker` (Render автоматически возьмёт готовый мультистейдж `Dockerfile`).
   - **Instance Type**: `Free`.
4. В разделе **Environment Variables** добавьте:
   - `DEMO_MODE` = `true`
   - `SYSTEM_REFERENCE_DATE` = `2026-11-16T11:30:00`
   - `JWT_SECRET` = сгенерируйте любую строку или оставьте автогенерацию
   - `GEMINI_API_KEY` = (опционально, ваш ключ Gemini для ИИ; без него работает детерминированный разбор)
   - `DATABASE_URL` = (опционально; если не указывать, приложение автоматически использует встроенную SQLite с предзагруженными данными сидинга).
5. Нажмите **Deploy Web Service**.

Через 2-3 минуты сервис будет доступен по адресу `https://servflow-xxxx.onrender.com`.

## Вариант 2: Бесплатная вечная PostgreSQL (Neon.tech)

Если вы хотите, чтобы в облаке работала полноценная внешняя PostgreSQL 16 вместо локальной базы:

1. Зайдите на [neon.tech](https://neon.tech) и войдите через GitHub (полностью бесплатно, без банковских карт).
2. Нажмите **Create Project** (выберите регион `Frankfurt`).
3. Скопируйте строку подключения `Connection String` вида:
   ```text
   postgresql://user:password@ep-xyz.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
4. Вставьте её в переменную окружения `DATABASE_URL` на Render (или Koyeb).
5. При первом запуске ServFlow автоматически создаст таблицы и выполнит сидинг всех 23 обращений, 12 кофемашин и 10 запчастей.

## Вариант 3: Koyeb.com (Без засыпания сервиса)

1. Зайдите на [koyeb.com](https://www.koyeb.com) и авторизуйтесь через GitHub.
2. Нажмите **Create App** → выберите **GitHub**.
3. Выберите репозиторий `ServFlow`.
4. В типе сборки выберите **Dockerfile** (порт автоматически выставится через `$PORT`).
5. Укажите бесплатный план **Eco / Nano** (Region: Frankfurt).
6. В разделе **Environment variables** задайте `DEMO_MODE=true` и `SYSTEM_REFERENCE_DATE=2026-11-16T11:30:00`.
7. Нажмите **Deploy**.

## Как легко вносить изменения

1. Вы делаете любые правки в коде на своём компьютере.
2. Проверяете тесты:
   ```bash
   python -m pytest tests/
   npm --prefix frontend run build
   ```
3. Делаете коммит и пуш:
   ```bash
   git add .
   git commit -m "feat: новые доработки"
   git push origin main
   ```
4. **Облачный сервис (Render / Koyeb) автоматически заметит пуш в GitHub**, запустит пересборку Docker-контейнера и обновит сайт в онлайне за 1–2 минуты без вашего участия.
